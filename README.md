## О проекте

Этот проект я использую как **портфолио-кейс для резюме**, потому что он хорошо показывает мои навыки в создании аккуратных многостраничных сайтов с понятной структурой, адаптивной версткой и деловой визуальной подачей.

Сайт разработан для компании, работающей в сфере экспортного сопровождения и международного B2B-взаимодействия. Основная задача интерфейса — презентовать компанию, показать экспертизу, описать услуги и привести пользователя к обращению.

## Моя роль

В рамках этого проекта я выступал как **Frontend Developer** и решал задачи по:

- верстке многостраничного сайта;
- построению структуры пользовательских сценариев;
- стилизации интерфейса под корпоративный сегмент;
- адаптации макета под мобильные устройства;
- организации мультиязычной структуры страниц;
- подготовке проекта в понятном виде для дальнейшей доработки и презентации.

## Какие навыки демонстрирует проект

### Frontend

- семантическая HTML-верстка;
- адаптивная верстка;
- работа с многостраничной архитектурой сайта;
- организация навигации между разделами;
- работа с формами обратной связи;
- подключение внешних библиотек и ресурсов;
- структурирование CSS для повторно используемых блоков интерфейса.

### UI / UX

- создание понятной информационной архитектуры;
- оформление корпоративного интерфейса в деловом стиле;
- работа с типографикой, контрастом и визуальной иерархией;
- проектирование пользовательского пути от знакомства с компанией до контакта.

### Работа с проектом

- поддержка читаемой структуры каталогов;
- подготовка проекта для GitHub и портфолио;
- базовая готовность к дальнейшему масштабированию и доработке.

## Что реализовано

- главная страница с hero-блоком и позиционированием компании;
- страница услуг с описанием сервисных направлений;
- страница команды с презентацией экспертов;
- страница контактов с адресом, картой и каналами связи;
- повторно используемые блоки формы обратной связи;
- мобильное меню для небольших экранов;
- английская версия основных страниц сайта;
- подключение фирменных шрифтов и визуальных ассетов.
