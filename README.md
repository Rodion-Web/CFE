## О проекте

Корпоративный многостраничный сайт для компании Centre France Export.

## Стек

* HTML5
* CSS3
* JavaScript
* jQuery
* Normalize.css

## Задачи

* Верстка многостраничного сайта
* Реализация адаптивного интерфейса
* Построение структуры страниц и навигации
* Интеграция формы обратной связи
* Поддержка мультиязычной структуры

## Реализовано

* Главная страница с hero-блоком
* Страница услуг
* Страница команды
* Страница контактов
* Мобильное меню
* Повторно используемые UI-блоки
* Англоязычные версии страниц
* Подключение кастомных шрифтов и графики

## Навыки

* Семантическая HTML-верстка
* Адаптивная верстка
* Многостраничная архитектура сайта
* Работа с CSS без фреймворков
* Базовая работа с JavaScript в интерфейсе
* Организация структуры frontend-проекта
* Работа с контентными корпоративными сайтами

```bash

cd CFE
```

Открыть `index.html` в браузере.
