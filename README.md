## О проекте

**Centre France Export (CFE)** — корпоративный многостраничный сайт с презентацией компании, услуг, команды и контактной информации.  
Проект выполнен в строгой деловой стилистике с акцентом на доверие, международную коммуникацию и понятную структуру контента.

README оформлен как кейс, чтобы репозиторий можно было показать заказчику, работодателю или использовать в личном портфолио.

## Цель проекта

Сайт решает сразу несколько бизнес-задач:

- презентует компанию и ее экспертизу в сфере экспортного сопровождения;
- показывает направления услуг и ценность для потенциальных клиентов;
- усиливает доверие через отдельную страницу команды;
- упрощает первичный контакт через форму связи и страницу контактов;
- поддерживает мультиязычную коммуникацию через французскую и английскую версии страниц.

## Что было реализовано

- главная страница с hero-блоком и ключевым позиционированием компании;
- страница `Services` с описанием сервисов и коммерческого предложения;
- страница `Team` с подробной презентацией экспертов;
- страница `Contacts` с контактами, картой и формой обратной связи;
- мобильное меню для навигации на небольших экранах;
- отдельная английская версия основных страниц;
- единая визуальная система на базе фирменных цветов, графики и типографики.

## Страницы сайта

### `index.html`

Главная страница с позиционированием бренда, кратким обзором услуг, преимуществ и блоком заявки.

### `services.html`

Подробное описание направлений работы компании, сервисного предложения и возможностей сопровождения клиентов.

### `team.html`

Презентация команды и отраслевых экспертов, усиливающая доверие к компании через персоналии и опыт.

### `contacts.html`

Контактные данные, карта, каналы связи и форма обратной связи для входящих обращений.

## Для заказчика

Этот проект подойдет как основа для:

- корпоративного сайта экспортной или консалтинговой компании;
- промо-сайта B2B-услуг;
- локализации бизнеса под международную аудиторию;
- презентации экспертной команды и направлений работы;
- быстрого запуска имиджевого сайта без сложного backend.

## Быстрый запуск

Так как проект статический, для просмотра достаточно открыть файл `index.html` в браузере.

## Что можно улучшить дальше

- подключить рабочую обработку формы в `send.php`;
- исправить кодировку текста на отдельных страницах, если сайт будет дорабатываться и публиковаться заново;
- добавить SEO-метаописания и Open Graph для красивого превью ссылок;
- оптимизировать изображения и шрифты для более быстрой загрузки;
- добавить полноценную адаптивную полировку для всех промежуточных разрешений.
