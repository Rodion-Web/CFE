## 📌 Описание

Многостраничный корпоративный сайт для компании **Centre France Export (CFE)**.

Проект использую как **портфолио-кейс для резюме Frontend Developer**, потому что он показывает мои навыки в создании аккуратных бизнес-интерфейсов, адаптивной верстке, структурировании контента и сборке классического frontend-проекта без фреймворков.

Сайт презентует компанию, услуги, команду и контактную информацию, а также поддерживает мультиязычную структуру страниц.

---

## ⚙️ Что реализовано

* Многостраничная структура сайта
* Главная страница с hero-блоком и позиционированием
* Страница услуг компании
* Страница команды с экспертами
* Страница контактов с картой и данными для связи
* Повторно используемые блоки формы обратной связи
* Мобильное меню для небольших экранов
* Англоязычная версия основных страниц
* Подключение кастомных шрифтов и графических ассетов

## 🚀 Запуск

### Требования

* Браузер
* Локальный сервер по желанию

---

### Локальный запуск

```bash
git clone <repo-url>
cd CFE
```

Открыть в браузере:

```text
index.html
```

Если нужен локальный сервер, можно использовать, например, Live Server в VS Code.
